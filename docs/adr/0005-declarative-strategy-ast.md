# ADR-0005: Declarative strategy AST and deterministic evaluator

- **Status:** Superseded by [ADR 0010](0010-python-strategy-scripts.md) (2026-11-28); accepted 2026-11-22. The Rule AST, its builder, compiler, evaluator and pipeline were removed.
- **Context:** Users define their own long/short rules; arbitrary code would be unsafe and unreplayable.
- **Decision:** The builder emits Rule AST v2 (JSON Schema `StrategyDefinition`): ALL/ANY/NOT, STATE, IN_ZONE with zone groups, AOI_TOUCH/OVERLAP, EVENT, SEQUENCE, COMPARE, IN_RANGE, CROSSES, PERSIST_FOR, WITHIN_BARS, TIME_WINDOW, RISK_REWARD. Plugins, AOI kinds, events and values come from the installed indicator plugins' metadata (ADR 0009). A pure tri-state (TRUE/FALSE/UNKNOWN) evaluator runs over `BarFrame`s; UNKNOWN blocks entries. A setup state machine (WAITING → AOI_TOUCHED → CONFIRMING → READY → FIRED, exits EXPIRED/INVALIDATED/CANCELLED/BLOCKED) deduplicates by scoped key. Versions are immutable and hashed; editing creates a new version without carrying activation.
- **Alternatives:** String expressions or user Python (rejected: injection, non-determinism); UI-only rules (rejected: not authoritative).
- **Consequences:** Backtest, replay, paper, shadow and live share one evaluator. Removing a node type makes old strategies fail validation with actionable errors; conditions are never silently dropped.
- **Migration:** A breaking AST change bumps `schema_version` and ships a migration; v2 is the only version today (the v1 starter-config import was removed on 2026-11-24).
- **Rollback:** Keep the previous evaluator version available for historical replay.
- **Amended 2026-11-24 (generic nodes):** the nodes and the risk target that named one indicator set's values, zones and sessions are replaced by generic ones. STATE: a plugin's published string or boolean values must match on each listed timeframe (ALL or K_OF_N). IN_ZONE: price inside a live AOI of the given kinds; a `group` binds members to AOIs with a shared `group_id`. TIME_WINDOW: local windows and weekdays in any IANA time zone, with no presets. EVENT and SEQUENCE take an optional plugin `source`; the risk target NEAREST_AOI takes `target_kinds`; signals report `group_ids`. `schema_version` stays 2, so other definitions keep their bytes and hashes; definitions with the replaced nodes fail validation. Compiler and evaluator are version 2.0.0.

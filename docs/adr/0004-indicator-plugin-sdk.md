# ADR-0004: Indicator plugin SDK and versioned outputs

- **Status:** Accepted (2026-11-22)
- **Context:** Indicators must be portable from Pine, testable bar by bar, and removable without touching each other or the OMS.
- **Decision:** Each indicator is an `IndicatorPlugin` package with `plugin_id`, `indicator_version`, input schema, warm-up, required streams and a pure `on_bar_closed(state, bar) -> (state, output)`. Plugins publish only `Aoi`, `StructureEvent` and documented scalar `values` inside an `IndicatorSnapshot`; consumers never read private state. Plugins never import each other (enforced). Outputs carry `method` (`pine_parity` vs `trade`) so enhanced models are never mistaken for parity.
- **Alternatives:** One monolithic indicator module (rejected: changes ripple); JavaScript indicators in the terminal (rejected: Python is authoritative).
- **Consequences:** Batch, incremental and checkpoint-replay runs must produce identical snapshots (property-tested). Built-in plugins ship with the engine; others come from installed plugin packages (ADR 0009). Golden Pine exports upgrade `parity_status` from `SPEC_ONLY` to `GOLDEN_VERIFIED`.
- **Migration:** A changed algorithm ships as a new `indicator_version`; saved strategies record the versions they were evaluated with.
- **Rollback:** Re-register the previous plugin version.
- **Amended 2026-11-24 (plugin metadata):** plugins declare what they publish and how it is drawn: `OUTPUT_KINDS`, `OUTPUT_EVENTS`, `OUTPUT_VALUES` (key, type, unit, choices) and `DISPLAY`, served as `output_kinds`, `output_events`, `output_values` and `display` in `IndicatorPluginInfo` and checked at registration. AOI kinds and event names are upper-case strings owned by the publishing plugin, not platform enums; kinds are unique across plugins, `AOI_INVALIDATED` and `AOI_EXPIRED` are reserved. AOI states are `active`, `tested`, `invalidated` and `expired`; a plugin-defined `group_id` ties AOIs of one structure together and a display-only `end_reason` says why one ended. Plugin `schema_version` 2 is the only one supported.
